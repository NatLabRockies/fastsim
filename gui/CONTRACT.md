## 1. Endpoints

### 1.1 `GET /api/schema`

```json
{
  "presets": [
    {"id": "2012_Ford_Fusion.yaml", "name": "2012 Ford Fusion", "pt_type": "Conv", "mass_kg": 1644.3}
  ],
  "cycles": [
    {"id": "udds.csv", "name": "UDDS (City)", "name_zh": "UDDS（城市）", "duration_s": 1369}
  ],
  "parameters": [
    {
      "path": "chassis.drag_coef",
      "name": "chassis.drag_coef",
      "group": "Chassis",
      "group_zh": "底盘",
      "subgroup": "Aero",
      "subgroup_zh": "空气动力学",
      "type": "float",
      "default": 0.393,
      "unit": "-",
      "description": "Aerodynamic drag coefficient.",
      "description_zh": "空气阻力系数。",
      "editable": true,
      "enum_options": ["FWD", "RWD", "AWD"]
    }
  ]
}
```

**Rules**

1. `parameters` is introspected from the **selected preset's** live `Vehicle.to_dict()`. It must cover **every** scalar leaf of the vehicle dict. Regenerate per preset: `GET /api/schema?preset=<id>` returns parameters for that preset (omitting `preset` → the first preset).
2. `path` = dotted path into the `Vehicle.to_dict()` tree, and **must include the concrete powertrain key**, e.g. `pt_type.Conv.fc.pwr_out_max_watts`. This is also the exact key used in `overrides`.
3. **Exclude these keys entirely** (not user inputs): `state`, `history`, `save_interval`, `doc`, `min_fastsim_version`, `db_path`, `soc_bal_iter_history`, `soc_bal_iters`, `pt_cntrl.RGWDB` internals are OK to include, but `cabin`/`hvac` when value is `None` are not parameters.
4. `type` ∈ `"float" | "int" | "bool" | "str" | "enum" | "curve" | "object"`.
   `editable: true` only for `float | int | bool | enum`.
   `curve` = nested interpolator objects (e.g. `…fc.eff_interp_from_pwr_out`) — **read-only**, shown so the user can see the curve exists. Never send them in `overrides`.
5. `unit` parsed from the field-name suffix:

| suffix | unit |
|---|---|
| `_watts` | `W` |
| `_joules` | `J` |
| `_kilograms` | `kg` |
| `_seconds` | `s` |
| `_meters` | `m` |
| `_meters_per_second` | `m/s` |
| `_meters_per_second_squared` | `m/s²` |
| `_square_meters` | `m²` |
| `_cubic_meter` / `_cubic_meters` | `m³` |
| `_kelvin` | `K` |
| `_watts_per_kelvin` | `W/K` |
| `_joules_per_kelvin` | `J/K` |
| `_kilogram_square_meters` | `kg·m²` |
| `_watts_per_square_meter_kelvin` | `W/(m²·K)` |
| `_watts_per_kilogram` | `W/kg` |
| `_joules_per_kilogram` | `J/kg` |
| `_kilograms_per_cubic_meter` | `kg/m³` |
| none | `-` |

6. `group` / `subgroup` mapping (both English and `_zh` variants required):

| path prefix | group | subgroup |
|---|---|---|
| `mass_kilograms`, `pwr_aux_base_watts` | Vehicle | Body |
| `chassis.drag_coef`, `chassis.frontal_area*` | Chassis | Aero |
| `chassis.wheel_rr_coef`, `chassis.wheel_fric_coef` | Chassis | Rolling & Traction |
| `chassis.wheel_radius*`, `chassis.wheel_inertia*`, `chassis.num_wheels`, `chassis.tire_code` | Chassis | Wheels |
| `chassis.wheel_base*`, `chassis.cg_height*`, `chassis.drive_*`, `chassis.glider_mass*`, `chassis.cargo_mass*`, `chassis.mass_kilograms` | Chassis | Dimensions & Mass |
| `pt_type.<T>.fs.*` | Powertrain | Fuel Storage |
| `pt_type.<T>.fc.*` | Powertrain | Fuel Converter |
| `pt_type.<T>.em.*` | Powertrain | Electric Machine |
| `pt_type.<T>.res.*` | Powertrain | Battery (ESS) |
| `pt_type.<T>.transmission.*` | Powertrain | Transmission |
| `pt_type.<T>.pt_cntrl*` / `dfco_cntrl*` / `alt_eff` / `aux_cntrl` / `sim_params.*` | Powertrain | Controls |
| `cabin.*` / `hvac.*` / `*.thrml.*` | Thermal | Cabin & HVAC / Battery Thermal |
| `pt_type` / anything else | Powertrain | Other |

### 1.2 `POST /api/simulate`

Request:
```json
{
  "preset": "2012_Ford_Fusion.yaml",
  "cycle": "udds.csv",
  "overrides": {"chassis.drag_coef": 0.30, "mass_kilograms": 1750},
  "render_matplotlib": true
}
```

Response:
```json
{
  "kpis": {
    "distance_mi":   {"value": 7.451, "unit": "mi",   "label_en": "Distance",         "label_zh": "行驶距离"},
    "fuel_economy":  {"value": 34.38, "unit": "mpgge","label_en": "Fuel Economy",     "label_zh": "燃油经济性"}
  },
  "timeseries": {
    "time_s": [0,1,2],
    "speed_target_mps": [0,0,0],
    "speed_achieved_mps": [0,0,0]
  },
  "matplotlib_png_base64": "iVBORw0KGgo..."
}
```

**KPI set — all of these, each `{value, unit, label_en, label_zh}`:**

| key | unit | label_en | label_zh |
|---|---|---|---|
| `distance_mi` | mi | Distance | 行驶距离 |
| `fuel_consumed_kwh` | kWh | Fuel Energy | 燃料能量 |
| `electricity_consumed_kwh` | kWh | Electricity Used | 耗电量 |
| `fuel_economy_mpgge` | mpgge | Fuel Economy | 燃油经济性 |
| `electric_economy_wh_per_mi` | Wh/mi | Electricity Economy | 电耗率 |
| `soc_start_pct` | % | SOC Start | 起始 SOC |
| `soc_end_pct` | % | SOC End | 终止 SOC |
| `energy_to_wheels_kwh` | kWh | Energy at Wheels | 车轮牵引能量 |
| `regen_recovered_kwh` | kWh | Regen Recovered | 再生回收能量 |
| `avg_speed_mph` | mph | Average Speed | 平均车速 |
| `max_speed_mph` | mph | Max Speed | 最高车速 |
| `trace_met_pct` | % | Cycle Trace Match | 工况跟随率 |

Values that do not apply to the powertrain (e.g. SOC on a Conv) must be **omitted** from `kpis`, not zeroed.

**`timeseries` keys** (omit a key when the vehicle has no such component; keep all arrays the same length = number of time steps):

| key | source |
|---|---|
| `time_s` | `cyc.time_seconds` |
| `speed_target_mps` | `cyc.speed_meters_per_second` |
| `speed_achieved_mps` | `veh.history.speed_ach_meters_per_second` |
| `grade_pct` | `cyc.grade` × 100 |
| `engine_power_kw` | `veh.pt_type.<T>.fc.history.pwr_prop_watts` ÷ 1000 |
| `motor_power_kw` | `veh.pt_type.<T>.em.history.pwr_mech_prop_out_watts` ÷ 1000 |
| `battery_power_kw` | `veh.pt_type.<T>.res.history.pwr_out_electrical_watts` ÷ 1000 |
| `soc_pct` | `veh.pt_type.<T>.res.history.soc` × 100 |
| `fuel_power_kw` | `veh.pt_type.<T>.fc.history.pwr_fuel_watts` ÷ 1000 |
| `cum_fuel_kwh` | cumulative `fc.state.energy_fuel_joules` ÷ 3.6e6 — approximate from history `pwr_fuel_watts` × dt |
| `cum_energy_kwh` | cumulative fuel + electricity |
| `cum_distance_mi` | `cyc.dist_meters` ÷ 1609.34 |

Simulation setup requirements: `veh.set_save_interval(1)` **before** running; a fresh `SimDrive` per request (never re-`run()`).

**Matplotlib figure** (when `render_matplotlib: true`): a clean 4-panel publication-style figure, 12×9 in, 140 dpi, white background, tight layout, sequential blue/orange/green/purple palette:
1. Vehicle speed — target (dashed) vs achieved (solid), m/s, `m/s` and `mph` on twin axis optional
2. Powertrain power split — engine kW, motor kW, battery kW (whichever exist), zero line shown
3. Battery SOC % (skip panel and show cumulative energy if the vehicle has no battery)
4. Cumulative fuel kWh and cumulative energy kWh vs time
Every axes: grid (alpha .3), axis labels with units, legend, title. Return base64 of PNG.

### 1.3 `POST /api/export-python`

Request: `{"preset": "...", "cycle": "...", "overrides": {...}}`

Response: `{"code": "<python source>"}`

**Code style — non-negotiable:**
- Flat, short, top-level statements only. No classes, no functions unless a KPI needs blocking, no builders/factories, no `main()`.
- Only `import fastsim` (+ `import yaml` only if truly needed). No web/UI/matplotlib/argparse code.
- Load the exact preset, then apply **only** the user's modified overrides.
- Overrides applied via `dict` mutation on `veh.to_dict()` → `fastsim.Vehicle.from_dict(...)`, using a compact nested-set helper **only if needed**; prefer direct key access when the path is 1–2 levels.
- Run the sim, then `print` the core metrics in a tidy aligned block.
- Must be directly executable with `python -c "<code>"` or as a file, with **zero errors**.
- Target ≤ 40 lines for typical overrides.
